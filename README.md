# amir-koutahi.github.io

Personal site for Amir Koutahi. One page, plain HTML/CSS, no JavaScript, no build step.
Hosted on GitHub Pages at amirkoutahi.com.

```
index.html     the whole site
styles.css     typography and layout
assets/pdfs/   self-hosted PDFs
```

To add a project, add an `<li>` under the right heading in `index.html`.
To add tutorial notes, see the comment in the Teaching section.
